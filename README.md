# Crypto Analysis Bot (Educational)

بوت تعليمي للتحليل الفني متعدد المدارس.

## التشغيل
1. انسخ `.env.example` إلى `.env` واملأ القيم.
2. `pip install -r requirements.txt`
3. `python bot.py`

## ملاحظات
- نظام الدفع واستقبال USDT غير مضمن لأسباب قانونية وأمنية.
- التحليلات تقريبية وتعليمية فقط وليست نصائح استثمارية.
- استخدم على مسؤوليتك الخاصة.
